# Code of conduct

Nuggets adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in the repository's issues, discussions and pull
requests, and anywhere else someone represents the project.

In short: be respectful and constructive, assume good intent, and don't harass anyone or
make personal attacks. Disagree about code, not about people.

## Reporting

If someone's behavior concerns you, contact the maintainers privately through the
repository's **Security** tab (**Report a vulnerability** creates a private thread; say
that it is a conduct report), or by email if a maintainer has published one on their
GitHub profile. Reports are kept confidential.

The maintainers decide on a response as the Contributor Covenant's enforcement guidelines
describe, from a warning to a permanent ban.
